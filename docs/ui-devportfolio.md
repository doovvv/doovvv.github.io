# devportfolio 风格调整

采用参考仓库的白底皇家蓝、IBM Plex Mono 等宽字体、大面积留白、网格与淡代码符号。首页使用开发者自我介绍；精选区与关于区采用左标题、右内容的比例。文章列表仍展示正文首图，阅读正文保留易读的中文字体。

保留已有导航、20 篇文章、46 条原有路由、搜索、主题切换、目录、评论及自动首图封面规则。不引入 Astro 运行时，继续使用现有静态生成器。

实施顺序：更新模板 → 统一样式与本地字体 → 构建所有页面 → 内容回归与浏览器桌面/手机验证。

验证：15 项既有测试、JavaScript 语法、生成页面中的本地资源、桌面和手机截图，以及搜索/导航/主题切换。

## 验证结果

- 构建47页，保留20篇完整正文与46条旧路由。
- 15项测试、JavaScript语法和diff空白检查通过。

- 桌面和390px手机显示无页面横向溢出；导航、搜索、精选切换与主题切换正常。
- 文章目录定位约110px，当前章节与阅读进度同步；16个机器学习公式正常渲染。
- 分享图为1200×630真实JPEG，已替换SVG引用。

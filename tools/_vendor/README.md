# Bundled Python dependencies

Pure Python runtime dependencies for offline article generation:

- Markdown 3.9 — https://python-markdown.github.io/ — BSD-3-Clause
- PyYAML 6.0.3 — https://pyyaml.org/ — MIT
- PyMdown Extensions 10.16.1 — https://facelessuser.github.io/pymdown-extensions/ — MIT

Downloaded from PyPI with pinned versions. Original license files are retained in each distribution's `*.dist-info/licenses` directory (or license metadata). Native extensions are omitted; PyYAML uses its Python implementation. No global Python environment is modified.
